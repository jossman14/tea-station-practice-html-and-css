# Tea Station

Latihan membuat situs statis toko teh ("Tea Station") dengan HTML, CSS, dan sedikit JavaScript.

## Isi

- `index.html`, `about.html`, `products.html`, `skills.html`: halaman-halaman situs.
- `css/style.css`: styling kustom.
- `js/app.js`: tombol buka/tutup navigasi.
- `images/`: gambar latar dan produk.
- `fontawesome-free-5.12.0-web/`: Font Awesome 5.12.0 (disertakan secara lokal).

## Cara menjalankan

Buka `index.html` langsung di browser.
